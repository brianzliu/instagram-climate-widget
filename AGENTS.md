# Project instructions

- Commit regularly in small, coherent batches as work progresses. Do not leave all changes for one final commit.
- Use Conventional Commits with a scope, for example `feat(dashboard): add action timeline`, `fix(extension): handle missing captions`, `docs(setup): explain Zen installation`, and `test(storage): cover demo isolation`.
- Build both Firefox/Zen and Chromium/Comet extension packages. Keep shared functionality consistent across them.
- Keep demo records separate from personal records. Label fictional data clearly.
- Caption suggestions require human review. Do not present a post as proof of a person's actual carbon footprint or character.
- Keep participant data local unless the user explicitly exports it. Do not add analytics, automatic posting, or external AI requests without an explicit product requirement.
- Run the build and relevant tests before the final handoff. Document known limitations honestly.
